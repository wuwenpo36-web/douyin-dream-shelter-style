# 单集简报模板

[返回首页](../README.md) · [中文阅读指南](reading-guide.md)

此模板依据原始 skill 整理，是新增的工作表。按本次任务选择需要的部分；制作单张图片或局部改图时无需填完整集。

## 基本需求

- 主题 / 单集名称：
- 交付物（创意 / 大纲 / 图片 Prompt / 改图 / 视频简报 / 室内 / 品牌）：
- 画面比例与时长（如适用）：
- 本次仅处理的片段或空间：
- 必须保留的内容：
- 已明确不要的内容：

## 职业与开场

- 角色职业与正在执行的任务：
- 可见的工具、衣物、载具或货物：
- 地点、天气、时间：
- 开场类型（灾前首帧 / 最后安全一秒）：
- 主威胁的位置、方向和接触对象：
- 环境原因 → 可见预兆 → 故障 → 路线中断：
- 身体姿势、支撑点与第一反应：

## 物件与变身

- 物件是什么、为什么属于当前场景：
- 开场中或取用时如何证明来源：
- 由哪只手抓握、执行什么动作：
- 接触 / 触发位置：
- 对应的材质、颜色、声音和扩散方向：
- 何时完全遮挡画面：
- 遮挡后首次可见的建筑局部：
- 必须延续的速度、方向、水迹、声音：

## 外观与进入

- 建筑形态、主题材料与功能：
- 用于证明巨型尺度的门、窗、层级和环境参照：
- 镜头距离、画面占比与是否允许完整外观：
- 外壳、入口与防护细节：
- 落地 / 接驳装置及消能方式：
- 从当前位置到门内的真实路线：
